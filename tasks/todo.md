# Shipping checklist

- [ ] Port build `6962` support and compatibility tests.
- [ ] Make structural validation the compatibility gate.
- [ ] Port managed-primary installation and recovery.
- [ ] Integrate subscription UI helpers and tests.
- [ ] Update version, changelog, fork URLs, and documentation.
- [ ] Run `npm run check` and `npm run release:check`.
- [ ] Run the dependency audit and secret scan.
- [ ] Verify the signed macOS application and runtime behavior.
- [ ] Review the final diff.
- [ ] Push, open the PR, monitor checks, and merge to main.
